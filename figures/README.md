# Figures

The local release candidate contains final PDF and PNG files for main Figures 1-4 and three Extended Data figures. They are withheld from the initial public Git commit pending approval of their copyright and redistribution terms.

`scripts/reproduce_figures.py` contains the reviewed routine for main Figures 1-4 and writes generated files to `figures/reproduced/` by default. The required aggregate source tables are also withheld until their data terms are approved. The final Extended Data images are retained locally, but their original standalone plotting routines were not available and are not claimed as script-reproducible.
